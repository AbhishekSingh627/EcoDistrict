# Dataset

Place labelled waste images here in the following structure:

```
dataset/
  train/
    plastic/
    paper/
    glass/
    metal/
    organic/
    e-waste/
    textile/
    other/
  val/
    (same structure)
  test/
    (same structure)
```

Images should be JPG or PNG, ideally 224×224 or larger.
Source: collect from public datasets (e.g. TrashNet, Kaggle waste datasets) or your own labelled photos.
